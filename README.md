# The Triplicate — `template_newspaper`

Render a 12-page US Tabloid newspaper (11″ × 17″) from structured YAML using
ReportLab. The included *Triplicate* edition is a fictional specimen inspired
by the Crescent City newspaper. Broadsheet is also supported.

- [Documentation index](docs/README.md)
- [Build and verify the edition and manuscript](docs/quickstart.md)
- [Edition contents and layout](docs/edition.md)
- [Manuscript on the layout engine](docs/manuscript/README.md)
