# Manuscript

The manuscript describes the newspaper layout engine. Open the
[build guide](../quickstart.md#render-the-descriptive-manuscript) for the exact
Template render and validation commands. The separate
[specimen build](../quickstart.md#build-the-specimen-edition) renders the YAML
edition and its illustrations into the 12-page newspaper.
