# Quantitative evidence

The [claim ledger](../../data/claim_ledger.yaml) ties the specimen's page count,
trim, and figure count to artifacts produced by the standalone scripts. The
[figure test](../../tests/test_figures.py) verifies the count against the
generator.

The [archived test report](https://github.com/docxology/template_newspaper/blob/288a465597fbcf4cb7ad02e6a836edcb917a5ed9/output/reports/test_results.md)
records coverage for its published snapshot. The
[current test command](../quickstart.md#run-the-native-checks) reports coverage
for the checkout under test.
